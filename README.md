# Islah Foundation website

A responsive, accessible Next.js public website for Islah Foundation. All programme status labels and legal claims should be reviewed by an authorized trustee before launch.

## Run locally

```bash
npm install
npm run dev
```

## Content and photos

Homepage content is in `src/app/page.tsx`. Replace the code-native image placeholders only with consent-cleared, optimized WebP/AVIF photographs from genuine activities. Never add unverified statistics, testimonials, partners, approvals, or beneficiary identities.

## Production setup

Before launch, replace placeholder contact channels and domain metadata, connect forms to a server-side validated provider, add rate limiting and spam protection, configure a headless CMS, and complete privacy/safeguarding reviews. Donations must remain inactive until PAN, banking, accounting, gateway verification and legal disclosures are ready. Publish reports only after approval and redaction review.
