# Launch checklist

- [ ] Replace draft email, phone, WhatsApp, domain and social links
- [ ] Supply consent-cleared genuine photographs and alt text
- [ ] Verify programme activity/status and coordinator details
- [ ] Confirm registration wording with the Trust Deed
- [ ] Review privacy, safeguarding, grievance, retention and media-consent policies
- [ ] Connect forms to approved email/database, CAPTCHA and persistent rate limiting
- [ ] Configure CMS roles and audit logging
- [ ] Set production environment variables and HTTPS
- [ ] Run accessibility, mobile, performance and security-header audits
- [ ] Confirm impact figures, partners, testimonials and stories remain hidden unless verified
- [ ] Keep donations disabled until all readiness requirements are satisfied
